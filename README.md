## Overview

This repository contains a frontend prototype for our SOEN 357 course project that aims to help university students compare off-campus housing options.


## Running the Project


```bash
npm install
npm run dev
```

Vite normally serves the project at:

```text
http://localhost:5173
```

## Mock Data

The current prototype is based on hardcode apartment data stored. This is done to be able to prototype well the features of the application using hardcode backend.
